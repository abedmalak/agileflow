## 📖 Overview

AgileFlow is a highly visual project management application designed to streamline workflows without overwhelming the user. Built with a focus on intuitive design and robust architecture, it leverages AI integration to create a seamless, well-organized experience.

**Tech Stack:** `React + Vite` • `Supabase` • `OpenRouter AI`

<br>

## ✨ Core Features

* **Interactive Kanban Boards**  
  Effortlessly organize tasks with smooth, drag-and-drop functionality.

* **Sprint & Backlog Management**  
  Structure your development cycles with clear, accessible sprint planning tools.

* **Analytics Dashboard**  
  Make data-driven decisions using beautifully rendered, real-time charts.

* **Calendar Integration**  
  Visualize deadlines and timelines in a centralized, responsive view.

* **Agentic AI Assistant**  
  Powered by OpenRouter, offering intelligent insights and contextual project assistance directly within your workspace.

* **Refined Dark Mode**  
  A modern, high-contrast dark theme optimized to reduce eye strain and maintain a quiet luxury aesthetic.
